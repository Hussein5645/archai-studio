# ArchAI 0.2.2.23 — Saved project destinations and online conversion

Plugins now use the project's saved link instead of selecting whichever project happens to be
open. Starting an unlinked bridge asks you to choose an existing project or create a new one.
Missing or inaccessible projects require choosing again. Cancellation sends no geometry.
The picker includes available online projects.

Linked projects sync in the background while you work in another project. Changing the link
clears pending batches, received hashes, update tokens and mesh/export caches. Revit resends
the visible 3D scene for the new destination. Reconnecting to an earlier project restores its
known source IDs and updates the existing binding graph instead of importing duplicate geometry.
ArchAI material assignments remain intact.

Putting a local project online keeps its project ID and converts its working copy to the online
project. Geometry, materials, bridge bindings and document settings carry forward. Existing
per-project viewport and bake storage remains attached on this device. Conversion does not
leave a second local project in the project list. The offline working copy supports the same
online project; saved bake output remains local to the device, as in the previous release.
Uploads use version checks, and failed conversion leaves the local project intact.

- App: **0.2.2.23** (web, Windows, Android/Quest).
- AutoCAD, Rhino, SketchUp, Blender, 3ds Max, Unreal: **0.5.4**.
- Revit 2024–2027: **0.5.4-beta.1**.

Install the updated app and plugins together, then restart source applications.
