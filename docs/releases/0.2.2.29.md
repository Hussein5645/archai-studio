# ArchAI 0.2.2.29 — Edit nested groups in place

Double-click a group to enter it and select its members individually. Double-click nested groups to move deeper. An **Editing group** breadcrumb bar shows the current context, with parent navigation, **Exit group**, and **Board / Sheet**. **Esc** exits one level.

- Layers shows only the active group's contents, with nested expansion and reordering. Double-clicking a group row enters it; **F2** renames a row.
- Outside objects fade on the 2D board. Clicks, box selection and Select all stay within the current group.
- The 3D workspace supports the same group context, individual member selection, highlights and transform controls.
- Drawing and paste add members to the active group while preserving world coordinates, including rotated groups. Copying nested members preserves their placement. Group navigation does not add undo steps; geometry edits remain undoable.
- Locked or hidden groups cannot be entered. Context is reconciled after deletion, undo/redo and online changes, and resets on document or sheet switches.

See [the group editing guide](../group-editing.md). This edits ArchAI document groups; a single imported mesh needs separate source elements to expose independent members.
