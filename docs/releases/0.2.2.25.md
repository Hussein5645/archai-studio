# ArchAI 0.2.2.25 — D5 folder import and automatic VR baking

The Windows desktop app can now read a saved D5 project folder directly. Choose **File → Import D5 project folder…** (also in the ArchAI menu and the 3D view's VR menu), select the folder containing `asset/1.save`, and review the conversion report.

**Import and bake VR** imports supported geometry and materials, creates an editable starting view if the project has no VR stops, and automatically starts baking in VR Preparation. Review the baked preview, then choose **Publish VR link** with your ArchAI account. No external Python converter or D5 installation is required.

Import is one undoable step and stops safely if the destination project changes during conversion. Repeated actors share geometry but retain their own placement. The report identifies known omissions instead of silently presenting a partial scene as complete.

## Experimental compatibility

Validated with the supplied version-11 Z-up curtain sample: one actor, two submeshes and 73,266 triangles with dimensions matching D5 metadata. Basic PBR properties, normals, UVs and explicit PNG/JPEG base-colour references are supported.

Terrain, grouped/scattered/procedural objects, native synced actors, D5 material style overrides, additional texture-map types, lights, environment, cameras and effects are not fully transferred. Rotated scenes and non-identity mesh instance matrices still need comparison against D5. ArchAI calculates new diffuse vertex lighting; it does not preserve D5's rendered lighting. The folder limit is 256 MB / 10,000 files and automatic baking requires at most one million triangles.
