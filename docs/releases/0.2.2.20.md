# ArchAI 0.2.2.20 — VR preparation and Live Bridge improvements

The VR menu now offers **Export Raw VR Link** and **Prepare Rendered VR Link**. The Windows
preparation workspace follows the board's elements/materials, prepares lighting and environment,
and publishes a walkable baked VR scene or a path-traced 360 image link. Existing raw links and
saved Render placements remain supported. Preparation includes quality presets, progress,
cancellation, stale-result checks and revision-safe publishing.

Raw exports batch compatible opaque meshes. Baked exports retain source textures, sampled
diffuse vertex lighting and the selected sky; compressed and mirrored geometry is preserved.
Glass, reflections, bounced texture colours and cutout shadows are approximated. This release
does not introduce path-traced texture-atlas baking. Single 360 images are monoscopic and use a
fixed viewpoint. Real headset performance remains to be measured.

Live Bridge changes include faster mesh-plan preparation, bulk source controls, corrected
placement/ownership handling, acknowledged mesh deltas, retries that retain transaction identity,
project-binding checks and source-refresh requests. Use matching 0.5.3 plugin builds.
