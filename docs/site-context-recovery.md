# Site context download recovery (0.2.2.31)

The packaged file:// renderer sent generic Electron identification to public OpenStreetMap data services. The primary Overpass endpoint rejected unidentified requests (406), while mirrors returned 500/504. The old error incorrectly described every failure as server load.

The desktop now adds an honest ArchAI User-Agent and project URL only to the allowlisted context-data endpoints, using Electron's outgoing-header hook. Renderer isolation and CORS protections stay enabled. A single bounded OpenStreetMap map.json request is hedged after four seconds for radii up to 500 m; larger, polar and date-line-crossing areas retain Overpass. This is a small manual-area fallback, not a bulk download mechanism.

The fallback reconstructs complete ways from nodes, skips missing-node geometry, filters to buildings/roads intersecting the requested circle (including crossing roads and enclosing footprints), and preserves existing editable solid conversion and attribution. HTTP-200 Overpass runtime errors are rejected rather than mistaken for empty coverage. Successful results are cached for five minutes (maximum twelve areas), concurrent duplicates share one request, results are copied for consumers, and losing requests/timers are aborted. Failures remain retryable and offer a smaller-radius fallback where applicable.
