# ArchAI 0.2.2.28 — VR uploads, imported materials, normals and live logs

VR publishing now sends assets in 8 MB parts instead of one request. This fixes publishing models larger than the former 95 MB request limit, including the reported 112.5 MB model size. Uploads retry transient part failures twice and stop stalled connections with an error. Assets up to 512 MB are supported; the previous published tour remains intact until its new manifest commits.

- **Replace all** matches an imported material's slot name across separate imported mesh blobs and asset definitions. Existing project-material overrides and locked elements are preserved when replacing source materials. Assigned project materials still use their library identity. The change is one undo step. Source materials with the same name are treated as the same slot; unnamed materials use `Material`.
- Select an imported mesh and open **Inspector → 3D model → Check source normals** to report missing/invalid shading normals, normals opposing triangle winding, and degenerate faces. Choose **Recalculate shading normals**, **Flip all faces**, or **Flip faces + recalculate**. Repairs are saved with the element, apply to 3D and VR exports, preserve the embedded original model, and support undo. Use **Original** to reset. Mixed face directions and degenerate geometry require repair in the source app; open surfaces do not have an automatically inferable outward direction.
- **Log** opens a live window on the board, Home screen and VR Preparation window. It retains the latest 500 task, command, warning and error messages for the current window's session. Pause scrolling, clear entries, or save a text log. Common credential patterns are redacted.

## Validation

- 680 application tests passed; four VR service tests passed, including multipart authorization, part limits and manifest commit behavior.
- Browser workflow verified live command logging and undoable normal controls.
- A local Cloudflare Worker/R2 test uploaded and downloaded 117,964,800 bytes (112.5 MiB) in 15 parts with matching SHA-256 and a committed tour manifest.
- Typechecking, production builds and installer smoke checks are recorded in the release verification.

The size test used a synthetic asset of the reported size. The user's original project and actual headset frame rate were not tested. Larger uploads do not guarantee that a headset can render a scene smoothly.
