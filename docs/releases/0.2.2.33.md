# ArchAI 0.2.2.33

Fixes an online-sync ordering bug that could reject a move or edit to a newly linked model, show "The edit no longer fits the document", and reload an older cloud project without that model.

Large model edits use HTTP while smaller edits use the live socket. Previously these could run concurrently, allowing a later move to reach the cloud before the model it referenced. Edits now wait for the previous batch to be acknowledged before sending the next, across both transports.

When an edit is genuinely rejected, ArchAI saves the complete local document as a separate project named "(recovered edits)" before reloading the cloud version. If that recovery save fails, synchronization pauses with the local model still open.

Validation: 123 unit-test files and 743 tests, including a delayed large-model upload followed immediately by movement and a rejection that waits for recovery before reloading; TypeScript and production web/Electron builds. Windows and web are updated; Android and iOS remain on their previous packages.
