# ArchAI 0.2.2.22 — ArchAI material priority and Revit visible-view linking

ArchAI now owns material assignments for every bridge element, including source-controlled and
shared presets. Source software can update geometry, placement and names according to their
existing permissions, while ArchAI slot assignments and surface paint remain intact. Whole-object
paint also covers new or renamed source slots. Stable source-material identities preserve project
materials edited in ArchAI when the source changes a material's colour. Unpainted mesh parts
continue to show their embedded source appearance.

Revit Live Bridge starts only from a non-template 3D view and exports its visible model, using
that view's geometry and detail level. Permanently hidden elements, hidden categories, and
temporary hide/isolate exclusions are filtered. View and visibility changes refresh the scope;
opening a plan or sheet suspends outgoing geometry without clearing the previous 3D scene.

View-hidden elements remain bound but hidden in ArchAI and excluded from outgoing links. Showing
them again restores their previous identity and ArchAI paint. Physical source deletions retain
the existing deletion/conflict protections. Manual `.AIR` exports remain document exports.

Install both the updated app and Revit plugin for view-scoped linking. Restart Revit after updating
the plugin, then start the bridge in the intended 3D view.
