# ArchAI 0.2.2.33

Fixes an online-sync ordering bug that could reject a move or edit to a newly linked model, show "The edit no longer fits the document", and reload an older cloud project without that model.

Large model edits use HTTP while smaller edits use the live socket. Previously these could run concurrently, allowing a later move to reach the cloud before the model it referenced. Edits now wait for the previous batch to be acknowledged before sending the next, across both transports.

When an edit is genuinely rejected, ArchAI saves the complete local document as a separate project named "(recovered edits)" before reloading the cloud version. If that recovery save fails, synchronization pauses with the local model still open.

Validation: 123 unit-test files and 743 tests, including a delayed large-model upload followed immediately by movement and a rejection that waits for recovery before reloading; TypeScript and production web/Electron builds. Windows and web are updated; Android and iOS remain on their previous packages.

## Analysis update — 19 October 2026

Sun hours, sun shadows, wind and noise now use opaque analysis colours across Natural materials, Warm clay, Architectural lines, Material colours and Structure. Material tinting, exposure and wireframe styling no longer alter the heat map. Architectural lines no longer pushes the analysis behind the model's faces. Legend colours and calculated quantities remain consistent across styles.

Noise analysis now supports rectangular **area emitters** as well as point emitters. Choose **Draw area emitter** in a noise analysis, drag its footprint, then resize or rotate it on the board. The emitter inspector includes shape, width, depth, height and sound-level controls; area markers are also visible and selectable in 3D. Point emitters and existing projects remain compatible.

An area's total reference sound energy is divided across nine sample sources, with distance loss and barrier screening evaluated per sample. This is an approximate outdoor screening model, not a calibrated acoustic simulation.

Updated validation: 744 unit tests across 123 files; GPU palette checks for all five styles and all analysis modes; numerical area-source energy/attenuation check; browser area drawing and inspector checks; existing analysis placement and view-editing regressions; production web/Electron builds. The refreshed Windows installer replaces the earlier asset on this same release.
