# Archai 0.3.0.9

Live Unreal views now use a direct mesh bridge. Archai sends binary vertex/index data and texture assets to its bundled Unreal runtime; live viewing no longer exports a GLB archive or runs an Interchange scene import. Assets have content hashes and are uploaded once per viewer session. The desktop host sends element additions, replacements and removals using stable Archai IDs and authenticated, ordered revisions. Unchanged elements remain in the scene. Geometry processing yields between elements, with progress reported to Archai.

Repeated geometry shares Unreal static mesh assets. Surface groups contain only their referenced vertices. World-aligned UV offsets are kept in material parameters so that repeated components can share geometry without moving their textures. Transforms, materials and lighting remain independent; camera, exposure and light changes do not rebuild Archai surfaces. Queued view updates are combined while synchronization is running.

The View tab includes an exposure slider from −4 to +4 EV, saved independently for each view and reflected in live rendering. Loading bars cover scene preparation, native element loading, image rendering, interactive export, VR publishing and saving view previews. Existing scene-baking progress remains available. Rendering/export dialogs show their own progress bar and desktop tasks report activity on the taskbar.

The first opening still builds and transfers scene data. This release does not introduce persistent caches across application/viewer restarts, automatic polygon reduction or cloud rendering. Archai still evaluates its scene geometry after model edits; the bridge avoids resending/reimporting unchanged geometry in Unreal. Image, Lightmass baking and portable interactive exports retain their dedicated output pipelines. Baked view previews retain the saved-bake loading path.

Local verification includes 200 repeated columns, geometry sharing, no live GLB files/imports, exposure without mesh rebuilding, updates confined to one moved/deleted element, three light types, native pointer selection/orbit, style switching, exact PNG dimensions, the baked-VR gate, selected-element interactive export and process cleanup. The five-second sample load is a local measurement for this repeated-column fixture, not a performance guarantee for large imported buildings. Standalone headset hardware and production publishing are not exercised by these checks.
