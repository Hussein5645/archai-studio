# ArchAI 0.2.2.24 — Live Bridge linking and panel controls

Live Bridge now opens the project-linking window automatically when an unlinked model connects or launches ArchAI. The separate Link to project button joins the same pending window. Cancelling dismisses automatic requests until the bridge is restarted.

Linking another model from the same app offers **Create new link** to keep both models, or **Replace** to remove a selected previous model's source geometry and disconnect its old link. Replacement is undoable. Reconnecting the same source keeps its existing binding.

The Live Bridge panel no longer inherits the desktop title bar's drag behavior. Dropdowns, tabs, checkboxes and scrolling remain interactive, including when many models are linked.
