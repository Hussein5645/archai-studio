Open ArchAI

Each plugin adds an ArchAI tab, panel or menu to the app with four actions: Send to ArchAI (save the model as an .AIR file to open in ArchAI), Live Bridge (keep the app and the ArchAI desktop app in sync while you work: your edits appear in ArchAI a moment later, and ArchAI's model comes back into the app; it starts ArchAI and opens a project for the model by itself), Open .AIR (bring an ArchAI design in), and Open in VR (walk through the model in a VR headset or any browser from a short link).

ArchAI in Revit

Native exchange: walls with layers, doors, windows, floors, levels and rooms become native elements both ways. Camera views and rooms become VR stops.

Revit 2024–2027 Send · Live Bridge · Open .AIR · VR Beta
How to install
  1. Close Revit and run the setup; it finds your Revit versions.
  2. Start Revit: the ArchAI tab appears on the ribbon.

ArchAI in AutoCAD

3D solids, surfaces, meshes and blocks go to ArchAI with their colours; .AIR files come in as one block per element on a layer per level.

AutoCAD 2025+ Send · Live Bridge · Open .AIR · VR Beta
How to install
  1. Unzip and copy the ArchAI.bundle folder to %AppData%\Autodesk\ApplicationPlugins.
  2. Start AutoCAD: the ArchAI ribbon tab appears (or type ARCHAIVR).

ArchAI in Unreal Engine & Twinmotion

An ArchAI menu in the Unreal Editor: static meshes go to ArchAI, .AIR files come in as placed meshes. Camera actors become VR stops. Twinmotion has no plugins: bring ArchAI models in through Unreal, or export from the source app.

Unreal Engine 5.1+ Send · Live Bridge · Open .AIR · VR Beta
How to install
  1. Unzip into your project's Plugins folder (so you have Plugins/ArchAI/ArchAI.uplugin).
  2. Restart the editor: the ArchAI menu appears in the main menu bar.
