# ArchAI 0.2.2.30 — VR tabletop sessions and cloud versions

Export raw scenes as editable tabletop models, or prepare baked scenes for VR exploration.

Updated on 2026-10-15 with automatic group normal repair. Select a group and click **Auto repair all mesh normals** in the Inspector to repair every imported mesh, including nested groups, in one undoable action. Connected faces become consistent, closed shells face outward, and shading normals are recalculated. Open surfaces keep their majority orientation. Repairs apply locally to ArchAI geometry even when a linked app controls the source model; no native-app access or ownership transfer is required. Source updates retain the correction, and no repair is sent back to the source app.

- The VR menu contains **Export Raw VR Link** and **Prepare VR Scene**. D5 folder import stays under **File**.
- Raw exports preserve individual element identities. In VR, one grip moves the table; two grips scale and rotate it. Aim at a floor and pull the trigger to enter at 1:1. **Tabletop** returns to the last placement. Desktop drag and wheel controls are also available.
- **Move elements** lets visitors move raw elements independently, with a selection outline. Edits remain in the browser session while exploring at 1:1. The ArchAI source document is unchanged.
- **Original** restores the published scene. The publishing owner can sign in to save or replace three cloud versions, separate from the original. Anyone holding the link can load those versions. Republished geometry cannot accidentally load transforms from an older model revision.
- Baked scenes offer the same table navigation and version slots, without individual element editing. Raw and baked 3D exports no longer require a VR stop.
