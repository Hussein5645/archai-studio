# ArchAI 0.2.2.27 — Larger projects on the board and in VR

Large imported projects now get a lighter preview in the board's **Low detail** mode. **High detail** retains the original supported geometry. VR preparation reduces a separate scene before baking, so a dense imported model no longer fails immediately at the former one-million-triangle input check.

## Changes

- D5 folder import reads the scene index and referenced assets on demand. The former 256 MB total folder limit and 10,000-file limit are removed. Conversion runs in a background worker with progress and cancellation.
- Unsupported D5 library formats are identified from their headers and reported without reading their full payloads. Repeated supported geometry is reused. Native version-11 meshes without an axis hint are handled as Z-up; missing material definitions receive named placeholders and a warning.
- Imported-model board previews target 350,000 triangles with a 10 mm simplification tolerance. VR reduction uses a 20 mm tolerance and each bake quality's triangle target, reserving room for independently lit back faces. Material boundaries and textured UV seams are protected. Tiny isolated components may be removed; review the result before sharing.
- The 2D plan reader uses preallocated typed buffers and avoids collecting invisible edges. Model decoding is serialized to reduce peak memory use.
- Large desktop working copies and model transfers to Render Studio use smaller IPC messages. Large embedded-model signatures are calculated without an extra escaped copy of the complete model string. Double-sided shadow casters no longer duplicate both windings in the lighting acceleration structure.

## Validation and limits

All 675 application tests pass, along with the browser D5 import-to-bake workflow, production typechecking, and the web/Electron build.

A supported 3,386,645-triangle D5 test scene imported, saved locally, reopened, and loaded in the native 3D workspace and Render Studio. Its Low detail preview contained 1,188,605 triangles. A full Fast-quality lighting bake produced a 1,571,336-triangle VR scene of 85,428,856 bytes (81.5 MiB). The complete bake test preceded the additional shadow-caster deduplication, which has separate occlusion and workflow checks.

Triangle targets are best effort: protected features and error tolerances can retain more geometry. Individual D5 resources/decoded mesh entries retain a 256 MB memory guard; scenes still above one million source triangles after reduction require smaller VR areas or a panorama tour. VR uploads retain the 95 MB limit. The existing 30,000-segment display cap per 2D edge/cut layer remains. Large chunked desktop working copies require this updated desktop version.

D5 import remains experimental. Unsupported grouped/scattered/procedural objects, terrain, opaque library formats, material overrides, lighting, cameras and effects may be omitted. The imported scene and bake must be reviewed; D5 render fidelity is not guaranteed. Actual Meta Quest frame rate still needs a headset test.
