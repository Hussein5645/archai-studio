# ArchAI 0.2.2.32

Linked models keep their board position in ArchAI. Moving a whole source group no longer sends that movement back as separate source-object moves. Individual elements still follow the source, ArchAI or shared transform authority selected in Live Bridge. Other linked apps continue to see the model's board placement.

Protected linked geometry now restores its source layer and the layer's position in the same operation. Previously, restoring children after their container disappeared failed document validation because the parent layer was missing. Empty complete source exports, including small models, now hold deletions for confirmation.

This release also includes:

- Desktop work continues while the window is minimized or behind other windows.
- CAI insertion waits for a saved project acknowledgement, updates existing instances by stable model identity and surfaces failures instead of placing duplicates. Modeling-window hydration and close/save races are fixed.
- Local saves commit geometry before the document, retain a previous working copy and wait for pending saves before project changes or window close. Invalid or incomplete local copies can fall back to the previous copy.
- The activity log can collapse to the latest three lines in a corner. Concept modeling has an accessible Back to project action.
- Large mesh scenes use a shared preview budget, queued preview work and cached raster board previews at low detail. Navigation reduces pixel density and temporarily hides dense edge overlays. Original geometry and export detail remain intact; preview reduction depends on mesh topology.
- Natural materials use softer lighting. View styles have clearer names and warmer clay and architectural-line appearances.
- Moving or resizing a location-map frame crops a fixed geographic plane. The site pin and geographic content stay anchored to the board.

Validation: 122 unit-test files, 741 tests; TypeScript and production web/Electron builds; six browser regression tests; packaged Windows background-task and project/modeling integrity smoke tests.

The Windows installer and web app are updated. Android and iOS packages remain at their previous release versions.
